本隐私政策说明「书签智能整理」（以下简称"本扩展"）如何处理你的信息。

## 一、核心承诺

**本扩展的开发者不运营任何用于接收用户数据的服务器，也无法接触、存储或获取你的任何书签数据。**

你的书签、配置和使用记录全部保存在你自己的浏览器本地。开发者不收集、不存储、不出售、不共享你的任何个人信息。

## 二、本扩展处理哪些数据

本扩展需要处理以下数据才能实现书签整理功能：

| 数据 | 用途 | 存储位置 |
|---|---|---|
| 书签标题、网址、文件夹结构 | 读取以进行分类、去重、生成整理预览 | 仅你的浏览器本地 |
| 你的配置（分类表、目标文件夹、界面选项） | 保持你的偏好设置 | 仅你的浏览器本地 |
| AI 接口地址与 API Key（若你启用 AI 分类） | 调用你指定的 AI 服务完成分类 | 仅你的浏览器本地 |
| 浏览历史：网址、访问次数、最后访问时间（若你启用「高频书签」） | 判断哪些书签是你最常用的，以便把它们平铺在分类文件夹的一级目录，一点即达 | **不存储**：仅在内存中即时算分 |

关于「浏览历史」需要单独说明。本扩展把浏览记录权限声明为**可选权限（optional permission）**——安装本扩展时**不会**要求这项权限，只有你在设置页开启（或在弹窗点「开启」）「高频书签」功能时，Chrome 才会弹出授权框，你可以拒绝。获得授权后，读取范围也只有**网址、访问次数、最后访问时间**三项，并且：

- **只读不写**：不会修改、删除或新增你的任何浏览历史记录。
- **不上传**：这些数据不会发往开发者的服务器，也不会发往任何 AI 服务商——「高频书签」完全在本地计算。
- **不落盘**：算分在内存中即时完成，不会把任何浏览历史写入扩展存储。
- **可拒绝、可撤回**：该权限是可选权限，只在你要用「高频书签」时才申请，拒绝授权不影响分类、去重等其他功能——此时「高频书签」自动降级为「仅手动标记」（你可以直接在弹窗列表里点星标记，手动标记不需要任何权限）。想停用可在设置页关掉开关，或在 Chrome 扩展详情页单独撤销「浏览记录」权限。

**本扩展不收集**：你的姓名、邮箱、电话、位置、设备标识、账号凭证、健康或金融信息、任何用于广告追踪的标识符。

本扩展**不包含**任何统计分析 SDK、广告 SDK 或崩溃上报服务。

## 三、数据在什么情况下会离开你的设备

**只有一种情况：你主动启用并配置了「AI 智能分类」功能。**

1. 你在设置页填写了第三方 AI 服务的接口地址与 API Key，并将分类方式切换为「AI 智能分类」；
2. 此时你点击扫描/分类，本扩展会通过 HTTPS，把**书签的标题与网址**发送到**你自己填写的那个接口地址**；随请求一并发送的还有**你在设置里填写的分类名称与关键词**（用于告诉 AI 每个分类收什么内容）——那是你自己的配置文本，不含任何额外的个人数据；
3. 默认情况下，请求里还会带上每个书签**当前所在的文件夹路径**（例：「台州项目 / 可研报告」）。它的用途是让 AI 认出你原有的归类习惯——你自己起的目录名（如「网文创作」）光看书签标题和网址是猜不出来的。**这是一项可以关闭的设置**：在设置页取消勾选「分类时参考书签现有的文件夹路径」，之后所有请求都不再包含任何文件夹信息（详见下方要点）；
4. 该接口返回分类结果，本扩展据此归类。
5. 设置页的「AI 建议大类」功能会发起**同一类**请求（同样只发到你填写的那个接口地址）：发送**书签的标题与网址**、**书签现有的文件夹路径**（同上，受同一个设置项控制），以及你填写的分类名称与关键词，用于向你建议该增删哪些一级大类。该功能由你主动点击才会触发，不点不会有任何请求。

除此之外没有其它任何数据离开你的设备。

关于这一过程的要点：

- **接收方由你决定**。本扩展未内置、未绑定任何特定 AI 服务商，不会把数据发往开发者指定的服务。你填哪个地址，数据就发到哪个地址。
- **开发者不经手这些数据**。数据在你的浏览器与第三方服务之间直接传输，不经过开发者的任何服务器。
- **该第三方的数据实践由其自身政策约束**。AI 服务商可能记录、处理或存储你发送的内容，请查阅你所选服务商的隐私政策。
- **文件夹路径可以不发**：是否发送书签所在的文件夹路径是一项独立开关（设置页「分类时参考书签现有的文件夹路径」，默认开启），取消勾选后请求里不含任何文件夹名。另外，无论开关状态如何，本扩展都会先在本地滤掉没有信息量的文件夹名（如「新建文件夹」「111」「待整理」）和插件自己创建的预览文件夹，这些内容不会出现在请求里。文件夹名是**你自己的文本**，可能包含私人信息（例如「辞职计划」），发不发由你决定，所以我们把它单独列出来告诉你。
- **你可以完全关闭**：在设置中把分类方式切回「关键词规则」，或在设置中清空 AI 配置。此后**不再有任何数据离开你的设备**，「关键词规则」模式完全离线运行。

## 四、权限用途说明

| 权限 | 为什么需要 |
|---|---|
| 读取和修改书签 | 本扩展的核心功能：读取书签树以分类、检测重复、生成预览、按你的确认重建文件夹结构 |
| 存储 | 在本地保存你的设置与撤销历史 |
| 右键菜单 | 提供「智能添加书签」入口 |
| 当前标签页 | 你点击右键菜单时，读取当前网页的标题与网址以创建书签。仅在你主动触发时临时生效 |
| 浏览记录（**可选权限**，安装时不申请） | 仅在启用「高频书签」功能时申请并读取，用于统计哪些网址你访问得又多又近，从而把这些书签平铺在分类文件夹的一级目录。只读取访问次数与最后访问时间，**不上传、不存储、不用于任何其他目的**（详见第二节）。拒绝授权不影响其他功能；可随时在设置页关闭该功能，或在 Chrome 扩展详情页单独撤销此权限 |
| 访问你填写的 AI 接口域名（可选） | 仅在启用 AI 分类时需要。该权限为可选，不启用 AI 时不会被请求；授权提示由你主动保存配置时触发，你可以拒绝 |

## 五、数据保留与删除

- 全部数据保存在你的浏览器本地（Chrome 的扩展存储中）。
- **删除方式**：在 Chrome 中移除本扩展，其本地存储的数据会一并被浏览器清除。
- 你可以随时在设置页「配置备份」中导出配置，或直接修改/清空任何配置项。
- 开发者无法远程访问或删除你本地的数据，因为我们根本没有这些数据的副本。
